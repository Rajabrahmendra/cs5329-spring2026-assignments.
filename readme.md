# CS5329 Spring 2026 - hello_algo.py

## Description
This Python script demonstrates basic algorithm implementation and system information retrieval for the CS5329 course.  
The script does the following:

1. Prints a welcome message.
2. Displays system information including Python version and operating system.
3. Performs a trivial computation by calculating the 10th Fibonacci number.

## Files
- `hello_algo.py` – main Python script containing the code.

## Usage

1. Make sure Python 3 is installed on your system.  
2. Open a terminal (PowerShell, Command Prompt, or VS Code terminal).  
3. Navigate to the project folder:
   ```powershell
   cd D:\cs5329-spring2026-assignments
````

4. Run the script:

   ```powershell
   python hello_algo.py
   ```
5. Expected output:

   ```
   Hello, Algorithms!
   Python Version: 3.x.x (your installed version)
   Operating System: Windows 10
   The 10th Fibonacci number is: 55
   ```

## Requirements

* Python 3.x
* Standard Python libraries (`sys` and `platform`) – no external packages required.
